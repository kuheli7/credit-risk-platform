What is the default rate by income type?

GENERATED SQL
SELECT income_type,
  COUNT(*) AS applicants,
  ROUND(100.0 * AVG(target), 2) AS default_rate
FROM application_data
GROUP BY income_type
ORDER BY default_rate DESC
